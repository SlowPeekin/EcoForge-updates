# EcoForge

**EcoForge** — a DayZ Central Economy workbench by Workspaces Creative.

Edit loot tiers, AI territories and area flags on an interactive map: paint tier zones
with shape tools, place and move spawn zones, preview what loot can spawn where, and
export byte-faithful `areaflags.map` / `env` XML straight into your mission.

## Download

Grab the latest **EcoForge-Setup** from the
[Releases page](https://github.com/SlowPeekin/EcoForge-updates/releases/latest).

The app checks this page for updates and can install them itself
(version badge → Check for updates).
